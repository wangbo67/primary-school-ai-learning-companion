# 《乌鸦喝水》可试玩学习脚本 v1

适用：约7岁、一年级，课后辅助。建议一位大人在身边帮助操作或记录原话，但不要提前说答案。主线约10—15分钟，时长是待验证的设计假设；孩子想停时可以停，不以速度或积分评价。

## 这次体验负责什么

1. 结合课文说明乌鸦喝不着水的原因。
2. 对照操作理解“一颗一颗”“渐渐升高”，区别水位升高与水变多。
3. 收起答案后，用自己的话讲述“办法—变化—结果”。

本次不承担全课12字的识字达标、5字的写字训练、朗读准确率评价或创造力评分。动画完成仅记录操作；选择题答对仅作为本次回答；作品和自我勾选不是自动掌握判定。

教材依据：项目中的《语文一年级上册（2024秋）》，第八单元阅读，第9课《乌鸦喝水》，书页97—98（PDF页102—103）。课后要求朗读课文、说说乌鸦用什么办法喝着水。本课识字：喝、只、处、找、着、许、石、出、法、放、进、高；写字：只、个、多、石、出。页面正文为课文选句；“听一听”和展开全文提供对应原文。现代设备合成朗读只作辅助，需大人关注多音字和语气，不作为标准示范录音。

## 共同行为规则

- 页面只有一条主线：找线索 → 试一试 → 我来讲 → 我的作品。
- 伙伴为固定脚本“小叶”，没有接入生成式AI。所有提示都有明确文本。
- 每站先留出约5—10秒思考空间；页面不自动倒计时，也不催促。
- 提示由孩子点击：第一次提供线索，第二次提供示范；之后可以重听，不无限追问。
- 播放音频必须主动点击；再次点“停一下”停止。无朗读能力时读文字或由大人读。
- 短句和大按钮优先；触屏点击与键盘都可操作，不要求拖拽。
- 答错不扣分，不说“你真聪明”；反馈指向眼前的条件或动作。
- 观察题和水位题答对后解锁下一站；无法独立完成时可听示范后作答，提示级别保留。
- 回到上一站保留本轮内容。刷新会开始新一轮，文字和录音没有自动保存；离开前用下载按钮保存。

## 01 找线索（约2—3分钟）

### 孩子看到与听到

画面：绘本乌鸦、水瓶剖面示意。两个可点击热点“看瓶口”“看水”。右侧课文选句及“为什么喝不着水呢？”问题。

初始伙伴：“点点瓶口和水，找一找线索。”

“听一听”朗读课文第一自然段。点击“到处”出现拼音、解释“这里找找，那里找找”，以及口头延伸“你找东西时，会到哪些地方找？”延伸不评分、不阻止前进。

### 操作与分支

| 操作 | 页面/伙伴反馈 | 记录 |
|---|---|---|
| 点击看水 | “瓶子里有水，可是水不多。”线索卡出现“水不多” | 水热点已看 |
| 点击看瓶口 | “瓶口又小，乌鸦的嘴伸不下去。”线索卡出现“瓶口又小” | 瓶口热点已看 |
| 选择“瓶子里没有水” | “再看看瓶子里的水和瓶口。你也可以点‘帮帮我’。” | 作答次数增加，不扣分 |
| 选择“水不多，瓶口又小” | “你找到了原因！水不多，瓶口又小，乌鸦喝不着。” | 本次问题已答对；允许前进 |
| 第一次求助 | “看看水离瓶口有多远，再看看瓶口。” | 提示1级 |
| 第二次求助 | “瓶子里有水，但水不多，瓶口又小，乌鸦够不着水。你也说一遍吧。” | 提示2级；不会伪装成独立完成 |

完成按钮：“我们来想办法”。页面不强制两个热点都点过，只要求回答原因。

大人观察：孩子是否能把“水不多”和“瓶口小”联系起来？他是读出原因，还是依靠听读、图片或你的帮助？请记录原话，不仅记选项。

## 02 试一试（约3—4分钟）

### 孩子看到与听到

沿用同一场景，六个石子操作按钮。右侧同步显示原文“一颗一颗地放进瓶子里”“渐渐升高”。点击词语可听解释并跟读。“听一听”读课文第二、第三自然段。

初始伙伴：“先听读，再放石子。慢慢来，我陪着你。”

### 操作与分支

| 操作 | 页面/伙伴反馈 | 记录 |
|---|---|---|
| 每点一颗 | 石子数增加，剖面示意中的水位逐步升高；“放一颗，再放一颗。水正在一点一点升高。” | 石子数，最多6颗 |
| 点“一颗一颗” | “放一颗，再放一颗。”“跟着动作读：一颗，一颗。” | 不作识字评价 |
| 点“渐渐” | “一点一点地变化。”“试着说：天渐渐……” | 口头使用词语，不自动评分 |
| 放满6颗 | 乌鸦：“谢谢你，我够得着水啦！”伙伴：“水位升高了！读读旁边的句子，再想想水有没有变多。” | 展示水位理解题 |
| 选择“水变多了” | “想一想，我们刚才有没有往瓶子里加水？” | 作答次数增加，仍可尝试 |
| 选择“水没变多，水位升高了” | “是的！水没有变多，是水位渐渐升高了。” | 解锁下一站 |
| 第一次求助 | “我们放进去的是石子，还是水呢？” | 提示1级 |
| 第二次求助 | “水没有变多。石子占了地方，水位渐渐升高，乌鸦就够得着了。” | 提示2级 |
| 点击“再试一次” | 本站石子与水位复位，需重新回答；保留本轮求助与作答累计 | 允许重放，不抹除求助证据 |

完成按钮：“我来讲讲这个故事”。

实验范围：这是表达课文因果的剖面示意，不是精确物理模拟；“6颗够到”仅是此示意的交互阈值，不代表真实瓶子一定如此。本版不提供羽毛、树枝等任意物品模拟，以免用错误规则暗示所有物体的效果。无实物实验要求。

大人观察：孩子只是在连续点石子，还是在观察并描述水位？能否用“渐渐”说一句其他情境的话？后者不作为过关条件。

## 03 我来讲（约3—4分钟）

画面收起课文、石子操作和完整答案。主问题：“乌鸦是用什么办法喝着水的？”

伙伴：“不着急，想一想再说。需要时，我会给你一点提示。”

孩子任选方式：

1. 直接口头讲给大人听（不需要麦克风）。
2. 主动点“录下我的故事”，允许浏览器使用麦克风，再说话；点“讲好了，停止录音”结束，或满2分钟自动结束。
3. 请大人在“我的话”输入框照录原话，最多2000字；不润色、不替写。

录音仅保存在页面内存，不上传，不转写，不自动评价。可以回放或下载。重新录音替换当前录音；如果要保留旧录音，应先下载。浏览器不支持或拒绝授权时，明确提示改为口头表达或大人记录，不阻止完成。

提示1：“先说乌鸦用了什么办法，再说水有什么变化，最后怎么样。”

提示2：“乌鸦把小石子一颗一颗地放进瓶子里，水渐渐升高，它就喝着水了。听完后，试着自己讲一遍。”

讲完后可和大人一起回想并勾选：

- 我说了乌鸦用的办法。
- 我说了水的变化。
- 我说了最后的结果。

这些是孩子/大人的自我回顾，页面不冒充AI听懂了故事。不要求三个都勾选，不要求录音或输入才允许继续。按钮“我讲好了，看看作品”由孩子主动确认；录音进行中须先停止。

大人观察：收起画面后能否说出因果顺序？用了哪一级提示？是孩子主动组织语言，还是逐句跟读？孩子没有讲时，不替他点击“讲好了”。

## 04 我的作品（约1分钟，可选延伸2—3分钟）

作品卡展示本次孩子原话及录音；没有文字或录音时明确说明没有保存记录，不自动生成一段漂亮故事冒充作品。

伙伴文字：“你留下了自己的故事。”“下次再讲给一个人听听吧。”

主按钮“保存我的学习记录”下载TXT文件，包含原话、新想法、自我勾选和本轮过程。录音需单独点“保存我的声音”。没有云端账户、公开发布或自动上传。

可选创作：“如果没有小石子……你想用什么办法帮乌鸦？”点击“我有一个新想法”后出现“我想用……这样做……”输入框，可以请大人照录，最多1000字。新想法同步放进作品卡，并标明“这是我的想法，还可以继续尝试”。不强制完成。

大人可参考的追问（由大人说，本版不会自动识别孩子的方案）：

| 孩子想法 | 建议追问 |
|---|---|
| “用吸管” | “吸管的一头要到哪里？另一头呢？” |
| “把瓶子倒过来” | “水流出来以后，乌鸦准备在哪里喝？” |
| “用棍子” | “你准备怎样用它把水取出来？” |
| 只说“用东西” | “你想用哪一样东西？准备怎么做？” |

先理解想法，不直接判错，也不未经验证承诺成功。孩子想画画，可画在纸上；本版不含画板和图片上传。

结束语：“今天先到这里，也很好。”无排行榜、连续签到、能力加分或强制下一课。

## 试用记录：用真实表现修改脚本

首次建议观察3—5名目标年龄儿童，作为发现交互问题的小样本，不据此宣称教育效果。先记录是否已在学校学过该课，避免把既有知识当成本次效果。

| 时点 | 大人做什么 | 记录什么 |
|---|---|---|
| 开始前 | 问孩子是否听过故事，愿不愿意一起试 | 既有熟悉程度、年龄、设备 |
| 过程中 | 尽量等孩子自己操作，必要时帮助读按钮 | 停住的位置、误点、求助、成人介入、原话 |
| 结束后 | 不显示课文，让孩子再讲一次；愿意时举个“渐渐”的例子 | 办法/变化/结果是否出现、是否需要提示 |
| 隔天有机会 | 口头问“乌鸦后来是怎么喝到水的？” | 是否还能组织表达；本版不自动提醒或追踪 |

观察表字段：儿童代号（无需姓名）｜是否学过｜开始/结束时间｜卡住环节｜主动求助｜成人帮助原话｜孩子讲述原话｜是否愿意再玩｜需要改的一个地方。

没有作答不等于不会，不愿录音不等于不会表达，听读后答对不等于独立识字。分别报告，不合成为能力分数。

## 内容与实现边界

- 插画：由内置 imagegen 生成并保存为 public/crow.png。提示词见 docs/插画来源.md。
- 水瓶：代码绘制的功能性剖面示意，随着真实页面操作更新。
- 朗读：设备 speechSynthesis，中文声音由设备提供；没有标准人声录音。
- 伙伴：预设脚本；未接入AI对话、自动转写、朗读评分或儿童能力诊断。
- 数据：本轮页面内存；下载由用户主动触发。刷新或关闭会丢失未下载内容。
- 页面：平板、电脑、手机可用；减少动态效果时关闭过渡。
- WebMCP：若浏览器支持，提供只读进度工具，不允许代理替孩子完成作答；无支持时不影响试玩。
