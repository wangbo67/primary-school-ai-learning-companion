# 小学生 AI 学习伙伴

把小学教材内容转化为孩子可以探索、理解、表达和创造的互动学习体验。

当前版本以一年级语文《乌鸦喝水》作为首个可试玩学习世界，包含四站互动：找线索、放石子与课文词语、独立讲述、可选新办法与作品下载。

## 在线体验

- 试玩版：https://crow-reading-adventure.widebook.chatgpt.site
- 给大人的完整学习脚本：https://crow-reading-adventure.widebook.chatgpt.site/script.html

当前在线版本为私密预览。面向其他人正式发布时，应另行确定公开托管方式和访问范围。

## 产品方向

本项目将每篇教材内容设计为一个“小学习世界”，共同遵循以下学习闭环：

1. 从课文情境提出问题。
2. 让孩子观察、尝试并阅读关键文字。
3. 收起答案，让孩子用自己的话表达。
4. 自愿留下声音、文字或创作作品。

AI 伙伴用于提供适量提示和理解开放表达。现阶段原型使用固定脚本，没有接入生成式 AI，也不进行自动能力评分。

## 当前原型

- 完整学习脚本：`docs/乌鸦喝水学习脚本.md`
- 可打印网页脚本：`public/script.html`，试玩页面顶部可打开。
- 课堂内容：`lib/lesson.ts`
- 互动页面：`app/page.tsx`
- 插画与最终生成提示：`public/crow.png`、`docs/插画来源.md`

## 运行

使用 Node.js 22.13 或更高版本（本次使用 Node.js 24）。

```sh
npm install
npm run dev
```

开发地址以终端实际输出为准。

```sh
node --test tests/lesson.test.mjs
npx tsc --noEmit
npm run build
```

修改学习脚本后，用 `python3 docs/render_script.py` 更新可打印 HTML。

## 真实能力边界

伙伴使用固定脚本，没有生成式 AI、自动转写、自动朗读评分或能力评价。浏览器合成朗读与录音取决于设备支持。录音、原话和创作留在本轮页面内存中，关闭或刷新前需主动下载；没有云端保存。
