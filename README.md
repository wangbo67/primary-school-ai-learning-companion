# 乌鸦喝水 · 小小语文探险

四站互动学习原型：找线索、放石子与课文词语、独立讲述、可选新办法与作品下载。

- 完整学习脚本：`docs/乌鸦喝水学习脚本.md`
- 可打印网页脚本：`public/script.html`，试玩页面顶部可打开。
- 课堂内容：`lib/lesson.ts`
- 互动页面：`app/page.tsx`
- 插画与最终生成提示：`public/crow.png`、`docs/插画来源.md`

## 运行

使用 Node.js 22.13 或更高版本（本次使用 Node.js 24）。

```sh
npm install
npm run dev
```

开发地址以终端实际输出为准。

```sh
node --test tests/lesson.test.mjs
npx tsc --noEmit
npm run build
```

修改学习脚本后，用 `python3 docs/render_script.py` 更新可打印 HTML。

## 真实能力边界

伙伴使用固定脚本，没有生成式 AI、自动转写、自动朗读评分或能力评价。浏览器合成朗读与录音取决于设备支持。录音、原话和创作留在本轮页面内存中，关闭或刷新前需主动下载；没有云端保存。
